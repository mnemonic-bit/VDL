# Security policy

## Supported versions

Security fixes are provided for the latest GitHub Release only. Older releases
and untagged development snapshots are not supported.

| Version | Supported |
| --- | --- |
| Latest GitHub Release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not report vulnerabilities in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/mnemonic-bit/VDL/security/advisories/new)
channel so the report and any supporting material remain private while they are
assessed.

Include the affected VDL version, deployment method, reproduction details,
impact, and any known mitigations. Never include real website cookie values,
VDL companion bearer tokens, pairing strings, signed media URLs, downloaded
media, personal URLs, or other credentials. Replace them with unmistakable
synthetic canaries before attaching logs or request examples.

This project is maintained on a best-effort basis. A report does not carry a
guaranteed response or resolution time, but actionable reports will be reviewed
as maintainer availability permits.
